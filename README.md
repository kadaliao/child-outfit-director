# 儿童时装导演

一个面向 Codex 的中文 Skill，为婴儿与儿童生成安全、非性感化的多套穿搭拼贴首帧、换装图片提示词和卡点短视频脚本。

## 安装

```bash
python3 ~/.codex/skills/.system/skill-installer/scripts/install-skill-from-github.py \
  --repo liyue-aigc/child-outfit-director --path skill --name child-outfit-director
```

或将本仓库内容复制到 `~/.codex/skills/child-outfit-director`。

## 范围

支持儿童日常、节庆、校园、运动、民族服饰和幻想主题；内置年龄适宜性、隐私和非性感化约束。该 Skill 只生成提示词和脚本，不替代服装安全认证或监护判断。
